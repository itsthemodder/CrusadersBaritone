CrusaderBaritone is an AI-powered Minecraft Bedrock addon designed to automate gameplay, navigation, combat, mining, and speedrunning tasks.

The addon features an intelligent hunter that can pursue targets, navigate the world, break blocks, collect resources, and perform various actions depending on its implemented systems and configuration.

Key Features:
🔴 Smart Navigation: Uses navigation logic to move toward targets and destinations while attempting to handle obstacles and getting stuck.

🟢 Combat & Hunting: Pursues targets and uses supported combat behaviours to engage them.

🔵 Automated Mining: Scans nearby blocks, identifies targets, and breaks selected blocks.

🟡 Speedrun Automation: Includes planned automation for progression tasks, resource collection, portal navigation, and Ender Dragon encounters.

🟣 Creative Flight: Optional Soul Torch-based flight functionality for chasing targets or moving around the world.

⚙️ Configurable Behaviour: Features can be adjusted through supported settings and toggles.

Compatibility: Minecraft Bedrock Edition. Check the specific addon version and its manifest requirements before installing.

CrusaderBaritone aims to make automated Minecraft gameplay more intelligent, adaptable, and efficient, with a focus on hunter AI and speedrun automation.

Note: Actual functionality depends on the installed version, configuration, and Minecraft Bedrock Script API compatibility.
